# store-tools-launcher

A single public page listing links to Shreemant Apna Bazar / Mitravinda's internal tools
(Store Assistant chat, Purchase Register generator). Published via GitHub Pages so it can be
shared with anyone as one memorable link -- but the tools themselves only respond on the store's
private network (Tailscale or store WiFi), so sharing this page alone gives no access to any
actual data. Add a new `<div class="tool">` block in `index.html` here whenever a new internal
tool is built, so this stays the one central hub.
